# Agentic — the AI assistant that lives on your Mac

Free, private, voice-first macOS AI assistant. Runs shell commands, works with files, browses the web, sees and controls the screen — and talks back with Amy, an offline neural voice.

🌐 **[agentic.is-a.bot](https://agentic.is-a.bot)** · ⬇️ **[Latest download](https://github.com/yousefelbanna2024-ship-it/agentic-releases/releases/latest)**

## Highlights

- 🎙️ **Voice mode** — hold-to-talk dictation plus hands-free conversation with barge-in, all offline (Whisper + Piper Amy)
- 🖥️ **Really uses your Mac** — 48 built-in tools: shell, files, web, screen control, reminders, subagents
- 🌐 **Agentic Browser** — agent browses in a window you watch, with find, zoom, history, downloads
- 🔌 **7 AI providers** — local Ollama, Gemini, OpenRouter, Groq, OpenAI, OpenCode Zen, or any custom server
- ♿ **VoiceOver-first** — every control labeled, every step announced

## Download

Get the latest `.dmg` from [**Releases**](https://github.com/yousefelbanna2024-ship-it/agentic-releases/releases/latest) (Apple Silicon, macOS 14+).

> First launch: right-click → Open, then confirm (not notarized yet — you do this once).

## Privacy

Local model = nothing leaves your Mac. Cloud providers get only what you send them. Conversations and keys stay in `~/Library/Application Support/Agentic/`. Voice is 100% on-device. Full policy: [agentic.is-a.bot/privacy](https://agentic.is-a.bot/privacy).
